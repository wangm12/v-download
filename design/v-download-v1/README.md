# V-Download black and white redesign pack

This pack contains the revised monochrome visual redesign for the video downloader app.

## Contents

- `index.html` - interactive design board containing all mockups.
- `exports/png` - individual 1440 x 1000 PNG mockups in black and white.
- `exports/pdf/v-download-bw-redesign-mockups.pdf` - all mockups combined into one PDF.
- `tokens/design-tokens.json` - monochrome color, type, spacing, radius, shadow, and layout tokens.
- `specs/redesign-spec.md` - UX rationale, screen behavior, component rules, and implementation priority.
- `specs/mockup-index.md` - index of every mockup file.
- `source/design_board.html` - source HTML/CSS for the mockup board.
- `source/export_mockups.py` - screenshot export script.
- `source/make_pdf.py` - PDF creation script.

## Design direction

The revised direction removes decorative color and uses a simple black and white system. The UI relies on hierarchy, spacing, border weight, labels, iconography, and surface contrast. Color-coded states are replaced by visible labels and neutral state treatments so the product feels calmer, more premium, and easier to implement consistently.
